# instagram-medien

Technische Ablage für Bilder, die auf Instagram veröffentlicht werden.

Instagram holt Bilder für einen Post von einer öffentlichen Adresse ab. Dafür legt ein automatischer Ablauf
hier pro Post einen kurzlebigen Zweig (`p/...`) mit den fertigen Bildern an. Nach wenigen Tagen wird der Zweig
wieder gelöscht, weil Instagram die Bilder dann längst kopiert hat.

Hier liegt nichts, was nicht ohnehin öffentlich auf Instagram erscheint: keine Zugangsdaten, kein Code, keine Entwürfe.

## Rechte an den Bildern

- Eigene Grafiken und das Maskottchen: alle Rechte vorbehalten.
- Medizinische Bilder und Illustrationen aus freien Quellen: Es gilt die Lizenz der jeweiligen Quelle.
  Urheber, Lizenz und Quelle stehen direkt im Bild und in der Bildunterschrift des zugehörigen Posts.

Bitte nichts von Hand in dieses Repository legen. Der Hauptzweig enthält nur diese Beschreibung.
